Citi Partnerships Portal

UX/UI
Project Overview
Partnerships Portal is  a dedicated space for partners and internal Citi teams to be able to track performance, and evaluate success of Citi partnerships through business, product and technology-driven metrics.
The Problem
Oversaw the launch and overall experience for Citi’s Partnership initiative and worked on the functional design and development of partners dashboard. Collaborated with developers, product managers, to create developer API catalogs, Documentation, API Sandbox and product management and more.
API Selection
Led the development of an API selection interface that streamlined the process, empowering developers to effortlessly choose, integrate, and optimize APIs according to their project needs.

API Keys
Apps are what you will create to solve your customer problems by integrating with Citi APIs. We identify your apps by issuing unique keys to them. The keys help us identify who's requesting access to our APIs and therefore helps us prevent malicious use.

Sandbox
In the recent overhaul of our API Sandbox, I orchestrated a transformative redesign aimed at providing developers with an enhanced testing environment. The revamped interface now offers an intuitive and user-friendly experience, allowing developers to experiment with API functionalities effortlessly.
‍
Product Documentation
Through meticulous restructuring and user-centric design, the revamped documentation streamlined partner onboarding, ensuring a seamless and efficient experience.The redesigned documentation not only provided comprehensive insights into product functionalities but also featured an intuitive structure for seamless navigation. 

File Transfers
The file sharing feature I championed seamlessly bridges efficiency and security. With an intuitive interface, our solution transformed document exchange, empowering teams with real-time collaboration and streamlined communication.
